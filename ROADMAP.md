# XivPrism roadmap

Published previews are design demonstrations. Check a milestone only after its acceptance evidence exists.

- [x] Standalone layout preview and sample feed
- [ ] Windows display enumeration, profiles and hotplug
- [ ] Android receiving-device separate/combined presentation feasibility
- [ ] Android and iPadOS companion shells
- [ ] Dalamud state publisher and HUD-family adapters
- [ ] Native Moonlight composition and input ownership
- [ ] Whole-surface pinning, then independent spatial panels
- [ ] Hardware compatibility records and measured performance

The feature vote informs priorities; it is not a shipping promise.
